# 2026-09-01 Nuxt 文档站稳定启动基线

## 1. 问题现象

- 项目曾经可以运行，后续修改后又无法启动。

## 2. 实际根因

- 用户确认过的稳定配置被继续扩散式修改，最小可运行组合失去约束。

## 3. 关键误导点

- 把“还能继续优化”误当成“可以随意改动稳定基线”。

## 4. 有效修复

- 记录精简依赖、`extends: ["shadcn-docs-nuxt"]`、单语 `zh-CN`、`ogImage.enabled = false`、`icon.clientBundle.scan = true`、`vite.ssr.noExternal` 等最小组合。

## 5. 验证方式

- 以 fresh 进程启动文档站，确认页面和关键 API 正常，再将配置标记为回归基线。

## 6. 后续约束

- 后续排错和优化必须以稳定基线为前提，不能为了局部问题重新改坏启动链路。
