# 2026-09-01 Nuxt 文档站启动前置缺失

## 1. 问题现象

- `nuxt dev` 无法直接启动，可能报缺少 `.nuxt`、组件库样式产物或 `#app-manifest`。

## 2. 实际根因

- 错误假设 workspace 依赖已经预构建完成，也假设 `.nuxt` 目录会预先存在。

## 3. 关键误导点

- 把文档站启动失败归因于组件库必须先产出 `dist`，忽略了文档站可以直接消费源码。

## 4. 有效修复

- 为 `dev/build` 增加 `nuxt prepare` 前置；为组件库及样式入口配置源码别名；按稳定基线关闭不稳定的 `experimental.appManifest`。

## 5. 验证方式

- 在没有预先生成组件库 `dist` 的前提下启动文档站，确认开发服务能正常启动并返回页面。

## 6. 后续约束

- 不要把文档站启动建立在组件库 `dist` 已存在这一隐含前提上。
